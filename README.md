# 🧸 Счётчик возраста

Персональный сайт-счётчик для новорождённого. Показывает возраст с точностью до секунды.

## Возможности

- Живой счётчик лет, дней, часов, минут, секунд
- Ввод имени и даты рождения
- Три цветовые темы: синяя, красная, зелёная
- Светодиодный режим с радужной рамкой и переливающимися цифрами
- Анимация падающих зверят (🐾)
- Адаптивный дизайн

## Деплой на Vercel

1. Загрузи репозиторий на GitHub
2. Зайди на [vercel.com](https://vercel.com)
3. Импортируй репозиторий
4. Vercel автоматически определит статический сайт — нажми **Deploy**

Готово! Ссылка появится через минуту.

## Локальный запуск

Просто открой `index.html` в браузере.
